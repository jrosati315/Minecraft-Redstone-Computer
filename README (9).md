# NOT Gate

[Component library](../README.md) · [Project overview](../../README.md)

A NOT gate inverts a single input. An unpowered input produces a powered output, and a powered input produces an unpowered output.

![Standalone not gate](../images/not-gate.png)

The central circuit is the single-input inverter. Neighboring circuits visible at the edges belong to other examples.

## Logic

`output = NOT A`

| A | Output |
| --- | --- |
| 0 | 1 |
| 1 | 0 |

Here, 1 means powered and 0 means unpowered.
